# POSIX-порт KAOS-RT

POSIX-порт предназначен для запуска KAOS-RT на хосте. Он удобен для разработки
прикладной логики и интеграции с программами POSIX. Порт не является прошивочной
реализацией для микроконтроллера.

Время берётся из `CLOCK_MONOTONIC` и переводится в логические тики
`FSM_TICK_FREQ_HZ`. По умолчанию это прямая шкала времени. Виртуальный узел
задаёт в `fsm_instance.h` начальное смещение и постоянную ошибку частоты. 
Постоянная ошибка интегрируется между чтениями времени. Критическая секция реализована через
`pthread_mutex_t`.

`port_uptime_usec()` возвращает 64-битное локальное время работы экземпляра
с момента `fsm_port_time_init()`. Ошибка частоты модели на него влияет,
начальное смещение — нет.

Поток-производитель моделирует периферийное IRQ и может вызывать только
`append_event()`.

Обработчики POSIX-сигналов не являются моделью IRQ для этого порта. Они не должны
вызывать API KAOS-RT, так как mutex нельзя безопасно захватывать из асинхронного
обработчика сигнала.

Для подключения добавьте `fsm_port.c` в сборку и включите каталог `port/posix/`
после каталога с заголовками приложения. Требуются POSIX.1-2008 и библиотека
потоков `pthread`.
