# Порт CH32V20x

Порт предназначен для семейства CH32V20x, включая CH32V203 и CH32V208. Он
использует 64-битный SysTick QingKe V4 как свободно работающий источник времени.

До компиляции задайте `FSM_SYSTICK_CLOCK_HZ` целочисленной константой, равной
активной частоте SysTick. Частота должна быть в диапазоне `1000000..UINT32_MAX`
и кратна 1 МГц и `FSM_TICK_FREQ_HZ`; несоответствие останавливает сборку.
Порт включает SysTick и не рассчитан на совместное использование этого счётчика
с библиотекой задержек приложения.

Заголовки WCH `ch32v20x.h` и `core_riscv.h` должны быть доступны через include
path проекта. Требуется компилятор с поддержкой RISC-V inline assembly GCC.
