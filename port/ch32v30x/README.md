# Порт CH32V30x

Порт предназначен для семейства CH32V30x, включая CH32V303, CH32V305,
CH32V307 и CH32V317. Он использует 64-битный SysTick QingKe V4 как свободно
работающий источник времени.

До компиляции задайте `FSM_SYSTICK_CLOCK_HZ` целочисленной константой, равной
активной частоте SysTick.
Порт включает SysTick и не рассчитан на совместное использование этого счётчика
с библиотекой задержек приложения.

Заголовки WCH `ch32v30x.h` и `core_riscv.h` должны быть доступны через include
path проекта. Требуется компилятор с поддержкой RISC-V inline assembly GCC.
