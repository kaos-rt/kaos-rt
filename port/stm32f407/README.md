# Порт STM32F407

Этот порт предназначен для STM32F407 и использует TIM2 как свободно работающий
32-битный счётчик логических тиков KAOS-RT. Он не является универсальным портом
для всего семейства STM32F4: перед применением на другом МК следует сверить
адреса регистров, наличие TIM2, его разрядность и дерево тактирования.

## Подключение

Добавьте `fsm.c` и `port/stm32f407/fsm_port.c` в список исходных файлов. В порядке поиска заголовков должны
быть доступны корень KAOS-RT, `port/stm32f407/` и заголовок
`stm32f407_min.h` приложения. Последний должен определять регистры и биты,
используемые портом: `RCC`, `TIM2`, `RCC_APB1ENR_TIM2EN`, `TIM_CR1_CEN` и
`TIM_EGR_UG`. Минимальный вариант такого заголовка есть в
[`example/stm32f407-black-board/Inc/`](../../example/stm32f407-black-board/Inc/).

В конфигурации сборки платы, до включения `fsm.h`, задайте фактическую частоту
входа TIM2:

```c
#define FSM_TIMER_CLOCK_HZ  UINT32_C(16000000)
```

Это значение не является частотой ядра и не задаётся портом: порт не знает,
какое дерево тактирования выбрано конкретной платой. Для STM32F4 оно равно
частоте таймеров APB1: при делителе APB1, равном единице, это `PCLK1`; при
большем делителе — `2 × PCLK1`. Значение должно быть кратно
`FSM_TICK_FREQ_HZ`, а вычисленный делитель должен помещаться в 16-битный
предделитель TIM2. Эти условия контролируются статическими проверками порта.

Порт сам включает тактирование TIM2, задаёт `PSC`, `ARR = UINT32_MAX`,
выполняет `TIM_EGR_UG`, обнуляет счётчик и запускает таймер при `start_fsm()`.
IRQ переполнения TIM2 расширяет его до 64-битного `fsm_port_uptime()`;
он возвращает локальное время работы МК в логических тиках. Не используйте
TIM2 и его IRQ одновременно в прикладном коде, HAL или другой библиотеке.

## Критическая секция и профилирование

Критическая секция использует `PRIMASK`: на короткое время запрещаются все
маскируемые IRQ, затем исходное состояние `PRIMASK` точно восстанавливается.
Из IRQ разрешён только `append_event()`.

При включённом `FSM_PROFILE_ENABLE` порт использует DWT `CYCCNT`; его единица
измерения — такт ядра Cortex-M. Показания профилировщика диагностические и не
заменяют измерение временных требований на целевой плате.

Готовый минимальный проект для STM32F407ZET6 Black Board находится в
[`example/stm32f407-black-board/`](../../example/stm32f407-black-board/).
