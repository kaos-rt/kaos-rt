# Пример контракта KAOS-RT для POSIX

Этот пример исполняемо показывает ключевые правила из
[контракта ядра](../../docs/KAOS-RT-CONTRACT.md). Программа работает
непрерывно; для остановки используйте `Ctrl-C`.

| Требование | Демонстрация |
| --- | --- |
| `KAOS-SRS-001` | В `fsm_instance.h` статически определены два автомата; `start_fsm()` вызывается до их регистрации. |
| `KAOS-SRS-002` | `controller_fsm()` и `one_shot_fsm()` выполняют только короткие действия над состоянием. Ожидание и печать вынесены в поток `reporter()`. |
| `KAOS-SRS-003` | Поток `event_source()` моделирует внешний источник: он вызывает только `append_event()`. Три одинаковых события, поставленные до запуска диспетчера, объединяются в один вызов обработки. |
| `KAOS-SRS-004` | `one_shot_fsm()` после однократного события удаляет собственный слот через `remove_fsm()`. |
| `KAOS-SRS-005` | Периодический таймер обслуживает `FSM_CONTROLLER`; одноразовый таймер запускает и завершает `FSM_ONE_SHOT`. |
| `KAOS-SRS-006` | CMake подключает POSIX-порт, в котором логическое время основано на `CLOCK_MONOTONIC`, а критическая секция — на POSIX-мьютексе. |

Периодический таймер каждые 100 мс увеличивает `steps`. Одноразовый таймер на
250 мс устанавливает `one_shot=1`; затем соответствующий автомат удаляется.
После события от внешнего потока `wakeups` становится равным двум.
Строка в консоли показывает наблюдаемое состояние, например:

```text
steps=10 wakeups=2 one_shot=1
```

## Сборка

```sh
cmake -S . -B build
cmake --build build
./build/kaos_posix_example
```

Требуются CMake, компилятор с поддержкой C17 и POSIX-потоки.
