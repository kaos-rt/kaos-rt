# Пример для STM32F407 Black Board

Пример предназначен для платы со STM32F407ZET6, двумя светодиодами на PF9/PF10
и кнопкой KEY0 на PE4. Он опрашивает кнопку один раз в 100 мс через
периодический таймер KAOS-RT и управляет LED0.

## Запуск в STM32Cube VS Code

1. Откройте каталог `example/stm32f407-black-board/` в Visual Studio Code.
2. Примените предложенные STM32Cube расширением bundles.
3. Выберите конфигурацию `Debug` и соберите проект.
4. Подключите ST-Link к плате и запустите отладку конфигурацией
   `STM32Cube: Launch ST-Link GDB Server`.

Пример использует HSI 16 МГц. В `CMakeLists.txt` задано
`FSM_TIMER_CLOCK_HZ=16000000`. При изменении дерева тактирования обновите это
значение вместе с настройками платы.

`Inc/fsm_instance.h` содержит список автоматов и событий приложения.
`Src/main.c` показывает регистрацию автомата и создание периодического
таймера.
